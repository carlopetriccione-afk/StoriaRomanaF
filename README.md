# Roma antica · appunti di storia romana (versione Fable)

Sito di studio in tredici pagine collegate, più la pagina iniziale e l'indice generale.

## Contenuto

- `index.html` — pagina iniziale
- `indice.html` — indice generale di parole chiave, personaggi ed eventi
- `repubblica.html`, `impero.html`, `personaggi.html` — la storia
- `istituzioni.html`, `diritto.html`, `esercito.html` — Stato, diritto, guerra
- `economia.html`, `societa.html`, `province.html` — economia e società
- `religione.html`, `letteratura.html`, `topografia.html` — cultura, religione, città
- `fonti.html` — fonti e metodo
- `esame.html` — preparazione all'esame: scritto e orale
- `assets/` — foglio di stile comune (`taste.css`), caratteri e icona

Il sito è statico: non richiede server né collegamenti esterni. I caratteri (Source Serif 4 e Libre Franklin, licenza SIL Open Font License) sono inclusi nella cartella `assets/fonts`.

## Pubblicazione su GitHub Pages

1. Crea un repository pubblico e carica tutto il contenuto di questa cartella, compresi `assets/` e il file `.nojekyll`.
2. In *Settings → Pages* scegli *Deploy from a branch*, ramo `main`, cartella `/ (root)`.
3. Dopo un paio di minuti il sito è all'indirizzo `https://NOME-UTENTE.github.io/NOME-REPOSITORY/`.

## Avvertenza

Le bibliografie moderne sono indicative: prima di citarle in un lavoro scritto verifica titolo, edizione e anno nell'OPAC SBN o nel catalogo della biblioteca d'ateneo.
